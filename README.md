# DataStats — Sistema de Encuesta Digital de Bajo Costo

## 📌 Descripción del Proyecto
DataStats es un sistema de encuesta digital de bajo costo diseñado para recolectar y analizar de forma automática la percepción de los usuarios sobre los proveedores de Internet (Entel, Tigo, Viva, etc.) en Bolivia. Opera mediante una Raspberry Pi y genera análisis estadísticos (frecuencias, promedios, porcentajes y gráficos) sin depender de conexión permanente a Internet ni licencias de pago.
